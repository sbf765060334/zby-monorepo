# ProTableActions 统一展示布局配置

ProTableActions 使用 `layout` 统一管理操作数量、全部展示与网格排列，直接移除顶层 `visibleCount` 和 `showAll`，不保留过渡属性，避免并行维护两套配置。数量模式使用 `layout.visibleCount`（非负整数或 `'all'`）；网格模式使用 `rows` 与 `columns`，两种数量规则互斥。

网格容量包含更多入口，只有操作溢出时才预留该入口，因此容量为六时可以展示六个操作，超过六个时展示五个操作与更多入口。

组件提供顶层 `width`，接受数字或 CSS 宽度；未传入时采用自然宽度，显式属性优先于 `style.width`。普通横向模式在空间足够时按自然宽度紧凑排列，空间不足时优先保留更多入口及间距，业务按钮共享剩余空间；短按钮只占所需宽度，释放的空间反复均分给所有尚未完整展示的按钮，分配不受操作顺序影响。更多入口及间距已占满可用宽度时，退化为仅展示更多入口，全部业务操作进入菜单；更多入口自身宽度构成最小占用宽度。

后续讨论已调整原先的列宽方案：不再提供 `columnWidth`。网格模式在指定整体宽度时先扣除列间距再等分列宽，未指定宽度时各列按本列内容的自然宽度排列。存在更多入口且单列宽度不足以完整容纳入口时，整组退化为仅展示更多入口。
