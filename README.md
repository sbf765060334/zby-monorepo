# zby-monorepo

A lightweight React component monorepo for `@zby/intl`, `@zby/ui`, and `@zby/pro`.

## Packages

- `@zby/intl`: shared internationalization utilities.
- `@zby/ui`: Ant Design v6 based supplemental UI components.
- `@zby/pro`: higher-level business components such as ProLayout.
- `playground`: Vite React playground for local development.
